Embeddings serve as dense numerical representations of unstructured data, mapping semantic meaning into high-dimensional vector spaces that facilitate efficient similarity search. Vector databases are specialized storage engines designed to index and query these vectors, often employing Approximate Nearest Neighbor algorithms to balance speed and accuracy. A popular structure for this task is the Hierarchical Navigable Small World graph, which organizes vectors into multiple layers to accelerate traversal. The construction of this graph is governed by parameters such as efConstruction, which dictates the size of the dynamic candidate list during node insertion. Increasing efConstruction results in a denser, more interconnected graph structure, thereby improving the potential search recall. However, this structural density comes at the cost of significantly longer index build times, as the algorithm must evaluate more neighbors to determine optimal connections. Conversely, the search process is controlled by the ef parameter, which sets the size of the candidate list during query execution. Setting ef to one is a critical misconfiguration that effectively disables the graph’s navigational advantages. With a list size of one, the search algorithm cannot explore alternative paths or backtrack, forcing it to follow a single greedy path that may lead to a local minimum rather than the global nearest neighbor, drastically degrading recall and rendering the index nearly as inefficient as a linear scan.

The choice of distance metric is equally critical. When embedding magnitudes vary significantly due to factors like document length or term frequency weighting, L2 distance, which measures Euclidean distance, is sensitive to these scale variations, potentially prioritizing magnitude over direction. Cosine similarity, in contrast, measures the angle between vectors, making it robust to scale differences and focusing purely on directional alignment. To optimize computation, vectors are often normalized to unit length before storage. This normalization allows Inner Product Search to approximate Cosine similarity because the dot product of two unit vectors is mathematically equivalent to the cosine of the angle between them. This property leverages the definition of the dot product, simplifying the calculation while preserving semantic relevance. Beyond these core mechanics, vector databases also support hybrid search, combining vector similarity with keyword-based retrieval, and employ quantization techniques such as Product Quantization to reduce memory footprint. Additionally, many systems offer sharding strategies to distribute load across multiple nodes, ensuring horizontal scalability for datasets containing billions of vectors.
